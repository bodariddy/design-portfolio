# Anmol Agarwal (anmolagarwal.vercel.app)
**Tags:** `hero` `motion` `detail` `navigation` · **Status:** 🟢 steal (mechanic)
**Why you picked it:** the card and the animations inside the screen, the old-TV feel.

## What it does
- **A line-drawn retro TV is the whole homepage.** Each project is a *channel* (CH 1, CH 2…), and a dial plus "turn the dial" hint changes it. Projects auto-cycle every few seconds.
- **The screen holds live, animated UI from the project:** cards sliding in, numbers counting ($2,540 → $872.26), progress bars. It's a mini demo, not a static screenshot.
- Title + one-line description + "Watch the demo / Open the live app" sit under the TV.
- A doodled cable trails off with handwritten italic notes ("tried a lot of things / stayed for the ones that fix a real problem").
- Achievements slide in as a card stack on the left.
- Warm off-white canvas (#F6F6F3), Inter + Instrument Serif + JetBrains Mono. Very restrained around one playful object.

## Take
- **One signature object that frames the work**, with projects as channels.
- **Animated product UI inside the frame,** e.g. Roqqu's balance counting up or a KYC step completing. It shows you design *interactions*, not just screens.
- The auto-cycle + manual dial pattern.
- Handwritten / italic annotations.

## Avoid
- Only one project visible at a time. Recruiters need the full list too, so pair the object with a project index.
