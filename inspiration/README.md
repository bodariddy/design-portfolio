# Inspiration

One file per reference: `inspiration/<slug>/notes.md` + `screenshot.png` (captured automatically when you share a link).

## How to add
Send a link, plus a line on what caught your eye if you can. I then:
1. Run `node inspiration/_tools/capture.js <url> <slug>`, which saves `hero.png`, `desktop-full.png`, `mobile-full.png` and `tokens.json` (fonts, colours, type scale, section headings)
2. Write `notes.md`: what works, what to steal, what to avoid
3. Add it to the index below with tags

We review each one together. **Status:** 🟢 steal · 🟡 maybe · 🔴 not for us
